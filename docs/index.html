📖 Overview

ks-ai-insert-table-check is an essential validator library and CLI designed for safe, idempotent Express.js API scaffolding.

Before writing any files or imports, it inspects your target directories to verify if base routing files exist, avoiding common code-generation failures.

It acts as a core validator for the KeshavSoft API Generation Suite, powering both automated orchestrations and VS Code extensions.

📦 Installation & Quickstart

Library Setup

Install the package via npm to run it in your application context:

npm install ks-ai-insert-table-check

SDK Usage

Import and invoke the synchronous validator in your node application:

import checkRoutes from "ks-ai-insert-table-check";

const result = checkRoutes("./src/routes");
console.log(result);

CLI Verification

Run via npx to quickly check local workspaces from terminal:

npx ks-ai-insert-table-check   [toPath]

CLI Parameters

  • 💡 raka: The key mapping (e.g. tableName)
  • 💡 poka: The output name
  • 💡 toPath: Optional directory path (defaults to current dir)
