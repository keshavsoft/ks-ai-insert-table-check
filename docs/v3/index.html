ks-ai-insert-table-check (Version 3) 🚀

Ensures target routing structures are present in the target workspace prior to inserting table routes.

📖 What's New in v3?

Version 3 aligns the file validation patterns with the latest pattern-collector-base-files dependency definition. It extracts configuration specifications using a structured fromRoutesJsEnd file type mapping to resolve the exact filename (e.g. routes.js) dynamically based on the current library version, and checks the target directory safely.

⚙️ CLI Usage (v3)

In version 3, the CLI command expects three positional parameters:

node bin/cli.js   [toPath]

Example:

node bin/cli.js purchases pokaValue ./test/v3

Response format:

{
  "KTF": true,
  "KReason": "file found : D:\\path\\to\\routes.js"
}

📦 API Reference

You can import the orchestrator function in your code to run the verification programmatically:

import checkRoutes from "ks-ai-insert-table-check";

const result = checkRoutes(targetDirectory);
if (!result.KTF) {
    console.error("Verification failed: ", result.KReason);
} else {
    console.log("Safe to insert table endpoints: ", result.KReason);
}
